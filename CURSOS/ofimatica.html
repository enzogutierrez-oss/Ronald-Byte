Ofimática y Herramientas Digitales

Domina las herramientas esenciales para el trabajo y estudio

📝 ¿Qué es la ofimática?

La ofimática es el conjunto de herramientas informáticas diseñadas para automatizar y mejorar las tareas de oficina: redactar documentos, crear hojas de cálculo, elaborar presentaciones y gestionar correo electrónico.

📄 Procesadores de texto: Microsoft Word

Word permite crear documentos con formato profesional. Funciones clave:
• Aplicar estilos y encabezados para estructurar textos.
• Insertar tablas, imágenes y gráficos.
• Revisar ortografía y gramática automáticamente.
• Exportar documentos como PDF.

🔢 Hojas de cálculo: Microsoft Excel

Excel organiza datos en filas y columnas (celdas) y permite:
• Realizar cálculos automáticos con fórmulas (=SUMA, =PROMEDIO, =SI).
• Crear gráficos de barras, líneas y pasteles.
• Ordenar y filtrar grandes volúmenes de datos.
• Generar tablas dinámicas para analizar información.

🖼️ Presentaciones y herramientas digitales

PowerPoint: crea diapositivas con animaciones y transiciones para exposiciones.
Google Drive: almacena y comparte archivos en la nube, editables desde cualquier dispositivo.
Google Docs / Sheets / Slides: alternativas gratuitas a la suite de Microsoft, con colaboración en tiempo real.
